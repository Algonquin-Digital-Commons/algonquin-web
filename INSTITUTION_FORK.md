# Algonquin Web Institution Fork

This repository is the thin Algonquin deployment fork of
`Post-Secondary-Digital-Commons/psdc-web`.

It owns Algonquin branding, approved web origins, identity issuer registration,
local legal and support links, enabled modules, institutional policy overlays,
release channel and deployment evidence. It does not fork common APIs, browser
security requirements, accessibility requirements or shared product semantics.

Common changes arrive through reviewed merges from the `upstream` remote. Reusable
improvements are proposed upstream before an Algonquin-only patch is considered.

> Status: Institution overlay specification complete; implementation not started
