# Contributing

All changes use a topic branch and pull request. Keep portable behaviour in this
repository and institution-specific branding or policy in the institution fork.

Before implementation begins, a change must identify its governing architecture
specification, contracts, threat and privacy impact, accessibility impact,
license and provenance, tests, failure behaviour, and rollback path.

Never commit credentials, production institutional data, unverified upstream
source, generated dependency directories, or proprietary assets. Contributions
use the repository license and preserve all applicable upstream notices.
